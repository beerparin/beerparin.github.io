Privacy Policy

Effective date: 21 November 2026

Bauliver Uploader ("the tool") is a private tool operated by a single creator for use with their own TikTok account. This policy explains what data the tool uses and how it is handled.

1. Data we access

When the creator signs in with TikTok, the tool may access, only for the creator's own account:

  • Basic profile information (open ID, display name, avatar) — scope user.info.basic
  • Profile statistics (follower, following, like and video counts) — scope user.info.stats
  • The creator's public video list and each video's view, like, comment and share counts — scope video.list
  • Permission to upload the creator's own videos to their TikTok inbox as drafts — scope video.upload

The tool does not access messages, contacts, other users' profiles or any data about viewers as individuals.

2. How we use data

  • To upload videos the creator has approved to the creator's TikTok drafts.
  • To produce private performance reports for the creator.

3. Storage and security

  • All data is stored only on the creator's own computer.
  • Access and refresh tokens are stored in files readable only by the creator's operating-system user and are never written to logs.
  • Statistics are kept as local report files and may be deleted at any time.

4. Sharing

We do not sell, rent or share TikTok data with any third party. Data is sent only to TikTok's own API servers as needed to perform the actions above.

5. Retention and deletion

Tokens are kept until the creator signs out or revokes access. Revoke access in TikTok under Settings and privacy → Security → Manage app permissions; the tool then deletes its stored tokens on the next run. Report files are kept until the creator deletes them.

6. Children

The tool is not directed to children and is used only by its adult operator.

7. Changes

Changes to this policy will be posted on this page with a new effective date.
